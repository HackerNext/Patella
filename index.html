One-Click Installable PWA Package (.zip)

When running inside an embedded preview iframe, browsers block native OS app installation (`beforeinstallprompt`) and sometimes restrict microphone prompts. Click below to download a complete, ready-to-install PWA folder containing index.html, manifest.json, sw.js, icon-192.png, and icon-512.png.

How to install the downloaded ZIP on Desktop/Phone:
1. Unzip the folder → run npx serve . or python3 -m http.server 8080 (or drag to Netlify Drop / GitHub Pages).
2. Open http://localhost:8080 in Chrome/Edge/Safari → click the Install Patella icon in the address bar!

Desktop Chrome / Edge

In a top-level tab, click the Install icon ⊕ in the address bar or Menu (⋮) → Save and Share → Install Patella.

iOS Safari & Android

iOS: Tap Share (↑) → Add to Home Screen.
Android: Tap Menu (⋮) → Install app / Add to Home screen.
