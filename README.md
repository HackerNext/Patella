# Patella — Progressive Web App (PWA)

## Quick Install Instructions (Desktop & Mobile)
1. Unzip this folder.
2. Serve this folder over localhost or HTTPS:
   - Using Node: `npx serve .`
   - Using Python: `python3 -m http.server 8080`
   - Or drag-and-drop this folder onto Netlify Drop (https://app.netlify.com/drop) or GitHub Pages.
3. Open the URL in Chrome, Edge, Brave, or Safari.
4. Click the "Install Patella" button in your browser's address bar (or Share -> Add to Home Screen on iOS).
